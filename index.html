② 新增积蓄分配器 · “我又攒了一笔钱怎么办？”

这部分只回答一个问题：“新攒下来的钱现在怎么分？”
基础规则：QQQ 30% + BTC 20% + SGOV 40% + 短线池10%。但SGOV会根据当前占比动态调整：<10%优先补、10%—20%维持、≥20%停止新增SGOV。因此不是每次都机械买40% SGOV。

③ QQQ / BTC 回撤作战台 · “SGOV什么时候拿出来？”

这部分与新增积蓄分配器不同。它只负责已经存在的SGOV战争储备。触发回撤后，按照阶梯从SGOV释放资金；执行买入后，再回到“当前资产”里更新实际成交结果。

⑤ SGOV战争储备状态

记忆规则：
SGOV <10% → 下一笔新增积蓄优先补弹药；
SGOV 10%—20% → 正常维持，不需要强行买SGOV；
SGOV ≥20% → 停止新增SGOV，新增资金主要进入QQQ/BTC；
市场回撤 → 不等感觉，按照阶梯机械释放。

⑥ 实际操作流程

正常时期：攒钱 → 输入新增积蓄 → 看②分配器 → 执行QQQ/BTC/SGOV/短线池 → 更新实际资产。
市场大跌：输入QQQ/BTC当前价格和ATH → 看③回撤阶梯 → 看作战指令 → 从SGOV执行对应金额 → 更新实际资产。
没有回撤：不要为了“用掉SGOV”而强行交易。下一笔新增积蓄再次进入②，由SGOV当前占比决定是否继续补弹药。
最重要纪律：同一回撤档位只执行一次。执行后必须更新资产并保存JSON，避免重复买入。
